# 织女

织女是一套面向企业业务场景的多用户协同与智能运营演示系统。

项目通过统一的业务工作台连接组织、用户、业务案例、运营流程和外部智能服务，展示大模型在企业实际工作中的辅助作用，帮助团队更清晰地理解业务信息、协同处理任务，并沉淀可复用的运营经验。

## 项目亮点

- **多用户业务协同**：支持不同用户在同一业务空间中协作处理工作。
- **业务案例管理**：围绕具体业务场景组织案例、过程和结果，便于追踪与复盘。
- **智能辅助运营**：将大模型能力接入业务流程，为信息整理、分析和决策提供辅助。
- **统一运营工作台**：集中管理业务目录、运行状态、组织身份和系统配置。
- **可扩展的外部集成**：预留模型服务及其他第三方系统的接入能力。
